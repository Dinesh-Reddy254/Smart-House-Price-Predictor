\# 🏠 Smart House Price Predictor



!\[Project Banner](https://images.unsplash.com/photo-1560518883-ce09059eeffa)



A \*\*Machine Learning web application\*\* that predicts house prices based on property features such as area, number of bedrooms, bathrooms, parking, and location preferences.



This project demonstrates the complete \*\*end-to-end ML workflow\*\*, including data preprocessing, model training, evaluation, and deployment using a web interface.

\## ▶️ How to Run Locally



Clone the repository:



```

git clone https://github.com/YOURUSERNAME/house-price-ai.git

```



Navigate to the project folder:



```

cd house-price-ai/app

```



Run the Streamlit app:



```

python -m streamlit run app.py

```



The app will open in your browser:



```

http://localhost:8501

```
